# Releases

The version history is [`CHANGELOG.md`](../../../CHANGELOG.md). Each release folder `bin-shaftmaster-vNN/` holds `RELEASE-NOTES.md` and `SHA256SUMS.txt`
(written by `tools/release.ps1`; `./tools/release.ps1 -Version vNN -DryRun` rehearses it into `artifacts/release-dryrun`). Release folders are never
edited after they are created.

- [`SHAFTMASTER-UI-RESULTS.md`](SHAFTMASTER-UI-RESULTS.md): the application and UI delivery (v01) and the pointer to the current release.
- [`STEP-EXPORT-RESULTS.md`](STEP-EXPORT-RESULTS.md): evidence of the STEP export.
