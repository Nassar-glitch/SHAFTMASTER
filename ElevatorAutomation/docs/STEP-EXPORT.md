# Preliminary STEP export

Open Elevator Solution.exe, create/open a project, enter its dimensions and floors, then choose DRAWINGS > Export STEP… and select the destination. Saving project JSON or generating DWGs first is not required. STEP always calculates the complete coordinated four-view design, independently of the DWG view checkboxes.

The same preliminary SOLIDWORKS solid workflow is used, with no extra preview formats. Millimetres; X shaft width, Y depth from entrance, Z elevation. Model sizes, rail/door selection, floor levels, cabin pose, counterweight pose, machine/sheave centers, hanger and support height come from Elevator.Core. NO STOP floors retain their landing slabs without landing doors or shaft door openings. The current accepted two-sheave arrangement is supported; unsupported direct routing / TZ beyond the reviewed range gives an explicit error instead of inventing equipment positions.

SOLIDWORKS must be installed, licensed and configured with a default **English-named Front Plane / Right Plane** part template. Tested with SOLIDWORKS 2022. The application bundles the two SOLIDWORKS interop DLLs, a compiled x64 worker, and reviewed reference JSON; there is no runtime compiler, Python, source-tree path, or development-output dependency. Keep all files in bin-solution-v01 together. STEP export itself does not require AutoCAD; existing DWG generation still requires AutoCAD 2023 and its existing template installation. Install/license SOLIDWORKS through the normal vendor installer; it is not embedded in this package.

The worker runs on an STA thread in a separate process. The desktop shows an indeterminate progress bar and component/export/verification stage text. Controls are disabled during generation to prevent input changes; the window remains responsive. Only worker-created documents are closed; pre-existing user documents are not saved or closed.

Before publishing, STEP AP214 is reopened and checked for millimetre units, solid count, solid faults, per-body extrema and volumes. Positive-volume component intersections are reported separately. They produce a review message rather than being hidden. Existing STEP replacement needs the save dialog confirmation; if another writer changes the destination during generation it is preserved and export fails clearly. Unsuccessful work retains its diagnostic source folder and never publishes an unverified final STEP.

Each export saves a unique sibling `<filename>_source_<id>` folder containing the editable Elevator_Assembly.SLDPRT, generated Parameters.json, exact project.elevator.json snapshot, source-body records, engineering statuses, verification.json and log. Edit the native model for local revisions, or change project inputs in Elevator Solution and export again for a regenerated model.

## Retained preliminary assumptions

No new detailed equipment model was introduced. Wall thicknesses: side 195, front/rear 200 mm; cabin panels 25 mm, floor 50 mm; frame members 25 x 80 mm; door leaves 20 mm; pulley axial breadth 100.0709 mm; governor width 50 mm. Guide rails retain simplified T70/65/9 and T50/50/5 sections. Channels use the engine-selected nominal depth with the previously simplified 65/7/9 mm flange/web dimensions, so this remains an envelope and not a manufacturer beam profile. Concrete supports retain 775 x 200 mm plan dimensions and calibrated positions. Shaft door openings use the existing simplified clear-width treatment. Machine and governor envelopes, panel thicknesses, opening breadths and local offsets retain the reviewed preliminary reference. Pitch-circle cylinders represent sheaves; true manufacturer outer envelopes are not verified. The governor remains independent from the deflector.

The original review discrepancies remain: drawing noise resolved in favour of stated CW depth 100 mm, Plan axes and A-A elevations control the assembly, governor X follows the MR shaft-left datum, and counterweight reference pose remains provisional. Room walls, ropes/reeving swept volume, bolts, grooves, brackets, buffers and manufacturer details are deferred. No full traction, D/d compliance, beam/hanger strength or manufacturer clearance certification is implied. Layout, wrap and code-diameter-ratio results stay independent; a nonblocking D/d warning/failure does not prevent STEP export.
